# Baseline Source Audit

**Repository:** `MB-Ndhlovu/ICT-MT5`  
**Audited baseline:** `e1d1a80bee2454ef507f89c69256036a0a97dd5e` (`main`)  
**Audit date:** 2026-10-15  
**Scope:** all 39 tracked files: the EA, all eight `.mqh` modules, Python backtest/demo scripts, result CSVs, reports, and project instructions.

The repository contains one production EA (`Experts/ICT_EA.mq5`), eight legacy includes, a synthetic/demo pipeline, multiple unrelated Python simulations, and checked-in result artefacts. There is no existing automated test directory. No code was changed while performing this baseline inspection.
